# Mi Cueva TIS · Mega Cueva Día 2

Landing de descarga de la Cueva TIS de Trade It Simple: un Director que conoce el método TIS,
4 agentes y 3 skills, listos en una carpeta para abrir en VS Code.

- `index.html` · la landing (un solo archivo, se publica con GitHub Pages).
- `mi-cueva-tis.zip` · el paquete que descarga el botón «Descarga tu Cueva TIS aquí».
- `assets/` · imágenes.

Para actualizar el paquete, sustituye `mi-cueva-tis.zip` por la nueva versión con el mismo nombre.
